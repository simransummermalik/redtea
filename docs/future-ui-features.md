# Future UI features

This list records concrete features from the previous setup screen that are not
available in the current interface. It is a backlog, not a commitment to restore
the old layout.

- **Choose how Yellow handles invalid words.** The old setup screen exposed an
  “Ignore invalid words” option. The current settings retain the default but do
  not let players change it. Consider restoring this as a Yellow Tea setting.
- **Show dictionary loading failures.** The old setup screen displayed whether
  the dictionary was ready, still loading, or failed to load. The current Start
  button is disabled while loading, but a load failure has no visible
  explanation. Add clear loading and error feedback so players know why they
  cannot start.
